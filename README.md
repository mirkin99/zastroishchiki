# Застройщики

Лендинги Nastebel для девелоперов.

## PIONEER

Последняя согласованная версия: `Pioneer/index.html`. Изображения и шрифты встроены в HTML, дополнительные файлы не требуются.

## Как получить ссылку на сайт

1. Откройте **Settings → Pages** в этом репозитории.
2. В разделе **Build and deployment**, поле **Source**, выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/(root)**. Нажмите **Save**.
4. Дождитесь завершения публикации: её статус виден на странице Pages и во вкладке Actions.
5. Лендинг будет доступен по адресу: https://mirkin99.github.io/zastroishchiki/Pioneer/

Важно: в настройках выбирается **/(root)**, а не папка Pioneer. GitHub Pages опубликует папку Pioneer как часть сайта.

После изменения `Pioneer/index.html` в ветке main сайт обновится автоматически. Регистр в адресе имеет значение: `Pioneer` с заглавной P.

Официальная инструкция: https://docs.github.com/ru/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
